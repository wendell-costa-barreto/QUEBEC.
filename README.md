# Visitez le Québec

Welcome to **Visitez le Québec**, a comprehensive and dynamic web app dedicated to showcasing the vibrant culture, scenic beauty, and lifestyle of Quebec, Canada. Whether you’re planning a trip or just curious about this amazing province, this site offers an immersive experience through detailed seasonal guides, city spotlights, local cuisine, nightlife, travel tips, and more.

## Project Overview

Visitez le Québec is a mobile-first web application built with React that provides an extensive guide to Quebec’s culture and lifestyle. Featuring over 50 pages, the app uses dynamic routing to deliver tailored content about different cities and seasons, allowing users to explore Quebec’s unique charm all year round.

From practical travel information — including legal requirements and transport options — to rich insights into local cuisine and nightlife, this app aims to be the go-to digital companion for anyone interested in discovering Quebec.

---

## Features

- **Dynamic Routes:** Explore Quebec through detailed city and seasonal pages that adapt based on user navigation.
- **Cultural Insights:** Deep dives into Quebec’s traditions, festivals, and way of life.
- **Travel Tips:** Information on how to get there legally, transportation options, and practical advice.
- **Cuisine and Nightlife:** Discover must-try dishes and popular spots to unwind after dark.
- **Responsive Design:** Fully responsive with Tailwind CSS to ensure a seamless experience on any device.
- **Smooth Animations:** Engaging UI transitions powered by Framer Motion for a polished user experience.
- **Content-Rich:** More than 50 pages of well-structured, engaging content.

---

## Technologies Used

- **React:** Core library for building the user interface.
- **Tailwind CSS:** Utility-first CSS framework for rapid, responsive styling.
- **Framer Motion:** Animation library to create smooth, interactive transitions.
- **React Router:** For managing dynamic routing and navigation.

## Getting Started

To run the project locally:

### Clone the repository:

```bash
git clone https://github.com/wendell-costa-barreto/QUEBEC./
```

## Install dependencies:
```
npm install
```
## Start the development server:
```
npm run dev

```
